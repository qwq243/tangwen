# 音效与环境音

全在 `web/audio.js` 里，**零素材**：整段声音都是 Web Audio 现场合成的（低频长音铺底 +
小调五声音阶上的偶发单音），所以一个字节的音频文件都不下载。

三条规矩，改它之前先读。

## 一、页面在后台就一声不许出

这条是实报「离开页面就不要声音了」之后加的。改之前 `on` 只管玩家那个开关，
切到别的标签页、切到别的 app，长音和偶发单音都照响。

现在三条路都拦：`visibilitychange`→hidden、`pagehide`（关页 / 跳走 / 进 bfcache 都走它）、
`freeze`（Chrome 的页面生命周期）。做法是**淡出之后把整个 AudioContext `suspend()`**，
不是把音量拧到 0 —— 拧到 0 那些振荡器还在跑，回头一看 CPU 白烧。

还有个容易漏的点：**后台期间连合成都不许做**，闸门要下在两处（`sfx()` 与排程那一层）。
因为 `suspend()` 之后 `ctx.currentTime` 是**停住的**，这时候排下去的音符全挤在同一瞬间，
切回来会「轰」地一起响。这是把 ctx 挂起而不是静音之后才会出现的坑。

回到前台：开关还开着就 `resume()` 加淡回原音量，排程接着排。

## 二、同一件事不许每次都一个样

原话是「不要太单调，增加随机性，否则用户会很烦躁」。两层分开做，别混：

| 层 | 怎么做 | 幅度 |
|---|---|---|
| 形状变体 | `pickVariant(key, [...])`：一件事备 2~3 支写法，选了之后**不连着重复**同一支 | 落印 3 支底子、解锁 3 支、悬停 3 支、滑卷 3 支、结案尾巴 2 支… |
| 参数抖动 | `jit(freq, cents)` / `rnd(lo, hi)`：音高、时值、增益各抖一点 | 音高 ±10~40 音分（100 音分＝半音，再多就「跑调」）、时值 ±10~25% |

第二层是「合成音色听久了发木」的解药：同一支写法连听两次也不完全一样。

**落印是听得最多的一件**（每一次提问都响），所以那里的分化最细：底子三选一
（金属 / 木头 / 砂面），尾巴按 `verdict` 分开 —— 是（轻轻一挑）/ 不是（闷的短叹）/
是也不是（三全音打架）/ 部分对（半步）/ 接近了（往上蹭半音）/ 无关和不重要（一层沙声）/
问清楚点（两记木叩）/ 不能剧透（低而硬的一记）/ 结案（两组走向随机）。
以前中间那七档是一模一样的响。

补过一遍「安静的地方」：点灯和吹灭（`wickOn` / `wickOff`）、灯语落地（`hint`）、
开卷第一声（`open`，跟音乐一起起）、搜剧本开合（`find`）、从搜索结果落卷（`seek`，
与滑卷区分）、停表和回表（`pause` / `resume`，极轻）、引导翻页（`tour`）、拖动（`drag`）。
以前这几件事要么没声音，要么借一声鼠标划过代替。

## 三、高频音必须节流

`MIN_GAP` 是一张表（悬停 110ms、拖动 95ms、滑卷 180ms…）。鼠标扫过一排按钮会连着触发
`mouseenter`，拖动画卷每一帧都可能出音 —— 不拦就是「嗒嗒嗒嗒」一梭子，比不响更烦。
探针量的是「12 次同步 hover 只落下一声」。

## 只读诊断

两枚，给排查和探针用：`FengcunAudio.state`（AudioContext 的状态）、
`FengcunAudio.playing`（此刻该不该有声音 = 开关开着 + 页面在前台）。

## 验收

```bash
node tools/audio-check.mjs http://127.0.0.1:8765/
```

它不往引擎里塞测试开关，而是在页面脚本之前把 WebAudio 的三个工厂
（`createOscillator` / `createBufferSource` / `createBiquadFilter`）包一层，
记下每次合成的「零件」，于是每次出音都有一条签名。

两把尺子分开用：**形状**（用了哪些零件）变了就是变体在工作，**精确签名**变了就是抖动在
工作。静音那几条走真事件（`visibilityState` 用 `defineProperty` 覆盖后派发
`visibilitychange`）。它顺带钉住「点灯 / 搜索 / 换卷的声音真的接在事件上」——
点一下，量到零件才算数。
